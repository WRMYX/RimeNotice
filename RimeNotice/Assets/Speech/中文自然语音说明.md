# RN 中文语音包下载

在“语音包下载”选择晓晓或云希并点击下载。文件默认保存到 Windows 当前设置的“下载”文件夹，支持迁移过的目录。同名文件另存，不覆盖原文件。

下载完成后显示完整文件位置；点击该路径或“打开所在文件夹”，在资源管理器中定位文件。文件不会自动运行。RN 不安装、卸载或解压语音包。

## 使用 NaturalVoiceSAPIAdapter

1. 从 https://github.com/gexgd0419/NaturalVoiceSAPIAdapter/releases 自行下载并配置工具。
2. 将下载的 MSIX 作为压缩包解压到固定目录。
3. 在该工具中设置“本地语音路径”，保留解压后的模型文件。
4. 在 RN“声音与语音”刷新本机语音，选择对应的 SAPI 声音并试听。

当前收录晓晓 1.0.9.0、云希 1.0.4.0，均为 x64 中文历史版本。适配器及语音包兼容性以其项目说明为准。RN 的语音下载与实际朗读为独立功能，下载成功不表示朗读兼容已通过。
