老师们在 QQ 群里发来通知，课堂电脑右下角的提醒却很容易被忽略。RimeNotice（RN）是一款面向 Windows 和教学触摸屏的 QQ 消息提醒工具：将收到的消息显示为独立通知卡片，配合消息分级、图片预览、提示音与正文朗读，让需要注意的内容来到眼前。

## 接收与提醒

- 专注 QQ 消息，提供 Windows 系统通知接收和独立的界面兼容接收方式；支持事件唤醒与定时扫描配置。
- 通过重要联系人、关键词和 @ 提醒区分普通消息、重要消息与呼叫，支持名单过滤及重复消息冷却。
- 新用户预置“老师”联系人和“作业、通知、课代表”关键词，可在设置中修改。
- 默认静默启动到系统托盘。关闭设置后继续接收，完全退出请使用托盘菜单。

## 通知外观与阅读

- 原生通知使用 ContentDialog 卡片与自带动画；材质通知提供独立外观，可选择 Mica、Mica Alt、亚克力或纯色。
- 长正文支持纵向自动滚动与手动浏览，发送人与正文可分别调整字体。
- 多条消息按顺序排队，等待中的消息不提前倒计时或播放提示音。
- 可调整消息颜色、Logo、遮罩、置顶、显示时长；呼叫边框呼吸默认关闭，可按需启用。
- 材质模式可分别设置渐显/渐隐、上下左右滑动及其时长与缓动；原生模式保留自身动画。

## 多图预览

- 同一条图片通知可在有界收集期内陆续补入多张图，Thumb/Ori 尽量归为同一张图片。
- 支持通知内网格和通知左/右侧显示，图片保持比例，支持滚动浏览和系统程序打开。
- 根据目录与时间匹配的图片会标记为推测。多个聊天同时保存图片时可能误关联，请以 QQ 原消息为准。

## 声音与朗读

- 普通消息、重要消息和呼叫可分别设置提示音，支持音量与混音优先级调整。
- 自动列出系统可调用的本机声音；默认只朗读正文，也可以选择朗读发送人。
- 中文自然语音 MSIX 仅提供下载与文件位置入口，不代为安装或卸载；需要外部语音适配工具的声音，由用户自行配置。
- 可选在线朗读默认关闭，启用后会向所选服务发送待朗读文本。

## 下载与第一次使用

- **MSIX 安装版**：下载 `RimeNotice-1.1.0.0-MSIX-with-certificate-x64.zip`。核对来源后信任随包公开证书，再安装 MSIX；首次使用在设置中授予通知访问权限。
- **便携版**：下载 `RimeNotice-1.1.0.0-Portable-x64.zip`，完整解压后运行 `RimeNotice.exe`。便携版不具备安装版的包身份，使用 UIA 兼容来源时需要 QQ 可见通知横幅。
- 首次启动后在系统托盘找到 RN，配置消息接收、提醒规则和声音，再使用调试预览检查显示效果。
- 图片预览请检测并核对自己的 QQ 图片目录；迁移过的 Windows 文档路径也需确认。
- 提供 `SHA256.txt`，供下载后核对文件完整性。Store 构建产物用于商店提交，不是此页的侧载安装包；商店公开状态以实际页面为准。

## 使用边界

- RN 不注入 QQ、不修改 QQ 文件、不读取聊天数据库，也不保存聊天历史。
- QQ 投递的通知可能只有摘要，RN 无法还原接口没有提供的全文。
- 界面兼容接收及系统材质取决于 QQ/Windows 版本和权限；打包成功不代表所有设备已经验证。
- 手动诊断采样可能包含通知原文与文件信息，分享前请检查并脱敏。
